Empat langkah, dari alamat baru sampai bersih lagiFour steps, from a fresh address to a clean slate

Dipakai untuk mengujiUsed to test
  • Email verifikasi pendaftaranSign-up verification emails
  • Tautan reset kata sandiPassword reset links
  • Notifikasi berlampiranNotifications with attachments
  1. 01

    Buat alamatCreate an address

    Panggil POST /api/addresses. Awalan dan domain boleh Anda tentukan, boleh juga dikosongkan.Call POST /api/addresses. Set a prefix and a domain, or leave both out.

    POST /api/addresses

  2. 02

    Kirim email ujiSend a test email

    Jalankan alur di aplikasi Anda dan arahkan emailnya ke alamat tadi.Run the flow in your app and point its email at that address.

  3. 03

    Baca hasilnyaRead the result

    GET /api/mailbox menampilkan isi kotak. GET /api/messages/:id memberi teks dan HTML satu email.GET /api/mailbox lists what arrived. GET /api/messages/:id returns one email’s text and HTML.

    GET /api/mailboxGET /api/messages/:id

  4. 04

    Hapus alamatDelete the address

    DELETE /api/addresses/me menghapus alamat beserta semua isinya.DELETE /api/addresses/me removes the address and everything in it.

    DELETE /api/addresses/me

API

API

Buat alamat, lalu baca kotak masuknyaCreate an address, then read its mailbox

Field prefix dan domain sama-sama opsional. Token dari jawaban pertama dipakai di semua panggilan berikutnya.The prefix and domain fields are both optional. The token from the first response goes on every later call.

Ketik 3 sampai 20 karakter.Type 3 to 20 characters.

qa-signup.<acak>@kotak.venbeemail.com

Pratinjau, belum membuat alamat.Preview only. No address is created.

TIKET API · No. 001API TICKET · No. 001
curl -X POST https://venbeemail.com/api/addresses \
  -H "Content-Type: application/json" \
  -d '{"prefix": "qa-signup", "domain": "kotak.venbeemail.com"}'
curl https://venbeemail.com/api/mailbox \
  -H "Authorization: Bearer $TOKEN"

Isi $TOKEN dengan nilai token dari jawaban pertama.Replace $TOKEN with the token value from the first response.

Awalan berisi 3 sampai 20 karakter dari huruf, angka, titik, garis bawah, dan tanda hubung. Karakter pertama dan terakhir harus huruf atau angka, dan dua tanda tidak boleh berdampingan. Server menambahkan akhiran acak, sehingga qa-signup menjadi alamat seperti qa-signup.62yt8v@kotak.venbeemail.com.A prefix is 3 to 20 characters of letters, digits, dots, underscores, and hyphens. It must start and end with a letter or digit, and two symbols cannot sit side by side. The server adds a random suffix, so qa-signup becomes an address like qa-signup.62yt8v@kotak.venbeemail.com.

Semua endpointEvery endpoint

Selain POST /api/addresses dan GET /api/health, setiap panggilan wajib membawa header Authorization: Bearer <token>.Apart from POST /api/addresses and GET /api/health, every call must carry the header Authorization: Bearer <token>.

Keberangkatan · /apiDepartures · /api

MetodeMethodJalurPathGunaPurpose
  1. POST/api/addresses

    Buat alamat baru. Mengembalikan alamat, masa berlaku, dan token.Create a new address. Returns the address, its expiry, and a token.

  2. GET/api/mailbox

    Daftar email di inbox, spam, dan sent, serta masa berlaku alamat.Lists the emails in inbox, spam, and sent, plus the address expiry.

  3. GET/api/messages/:id

    Satu email lengkap: metadata, teks, dan HTML.One full email: metadata, text, and HTML.

  4. PATCH/api/messages/:id

    Pindahkan email antara inbox dan spam lewat field folder.Move an email between inbox and spam with the folder field.

  5. GET/api/messages/:id/attachments/:n

    Unduh satu lampiran dari sebuah email.Download one attachment from an email.

  6. DELETE/api/addresses/me

    Hapus alamat beserta semua isinya.Delete the address and everything in it.

  7. GET/api/health

    Periksa apakah layanan sedang berjalan.Check whether the service is running.
