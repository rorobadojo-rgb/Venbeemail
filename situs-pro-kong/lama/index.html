Cara kerja

Empat langkah, dari alamat baru sampai bersih lagi

  1. Buat alamat

    Panggil POST /api/addresses. Awalan dan domain boleh Anda tentukan, boleh juga dikosongkan.

  2. Kirim email uji

    Jalankan alur di aplikasi Anda dan arahkan emailnya ke alamat tadi.

  3. Baca hasilnya

    GET /api/mailbox menampilkan isi kotak. GET /api/messages/:id memberi teks dan HTML satu email.

  4. Hapus alamat

    DELETE /api/addresses/me menghapus alamat beserta semua isinya.

API

Buat alamat, lalu baca kotak masuknya

Field prefix dan domain sama-sama opsional. Token dari jawaban pertama dipakai di semua panggilan berikutnya.

Buat alamat 
curl -X POST https://venbeemail.com/api/addresses \
  -H "Content-Type: application/json" \
  -d '{"prefix": "qa-signup", "domain": "kotak.venbeemail.com"}'

Awalan berisi 3 sampai 20 karakter dari huruf, angka, titik, garis bawah, dan tanda hubung. Karakter pertama dan terakhir harus huruf atau angka, dan dua tanda tidak boleh berdampingan. Server menambahkan akhiran acak, sehingga qa-signup menjadi alamat seperti qa-signup.62yt8v@kotak.venbeemail.com.

Baca kotak masuk 
curl https://venbeemail.com/api/mailbox \
  -H "Authorization: Bearer $TOKEN"

Isi $TOKEN dengan nilai token dari jawaban pertama.

Jawaban berisi

Bagian sebelum tanda @

Daftar lengkap

Semua endpoint

Selain POST /api/addresses dan GET /api/health, setiap panggilan wajib membawa header Authorization: Bearer <token>.

  • POST/api/addresses

    Buat alamat baru. Mengembalikan alamat, masa berlaku, dan token.

  • GET/api/mailbox

    Daftar email di inbox, spam, dan sent, serta masa berlaku alamat.

  • GET/api/messages/:id

    Satu email lengkap: metadata, teks, dan HTML.

  • PATCH/api/messages/:id

    Pindahkan email antara inbox dan spam lewat field folder.

  • GET/api/messages/:id/attachments/:n

    Unduh satu lampiran dari sebuah email.

  • DELETE/api/addresses/me

    Hapus alamat beserta semua isinya.

  • GET/api/health

    Periksa apakah layanan sedang berjalan.
