# Daftar Periksa Mata (G5)

Untuk hal yang tidak bisa dihitung skrip. Jawab tiap butir: pass, warn, atau fail, dengan catatan.

## Gambar

| Butir | Lulus bila | Diperbaiki oleh |
|---|---|---|
| Gambar pertama | Tanpa teks dan kolase; karya terlihat jelas saat diperkecil menjadi thumbnail persegi | wall-art-mockup-art-director |
| Karya asli | Karya di semua mockup adalah karya yang dijual, tidak digambar ulang | wall-art-mockup-art-director |
| Skala jujur | Ukuran karya di mockup sesuai ukuran yang ditawarkan | wall-art-mockup-art-director |
| Bingkai | Bila bingkai terlihat, ada penyebutan "frame not included" | wall-art-mockup-art-director |
| Unduhan digital | Minimal satu gambar menyebut digital download | wall-art-mockup-art-director |
| Tanpa klaim palsu | Tidak ada lencana, bintang, atau klaim penjualan | wall-art-mockup-art-director |

## Teks

| Butir | Lulus bila | Diperbaiki oleh |
|---|---|---|
| Judul benar | Menggambarkan produk yang dijual, tanpa merek atau karakter | etsy-listing-copy-builder |
| Angka selaras | Jumlah file, rasio, dan ukuran sama di deskripsi, lembar ukuran, panduan cetak, dan manifest | etsy-listing-copy-builder |
| Syarat pemakaian selaras | Sama di deskripsi dan panduan cetak | etsy-listing-copy-builder |
| Penyebutan AI wajar | Ada bila berlaku, jujur, tidak disembunyikan di akhir dengan kalimat kabur | etsy-listing-copy-builder |
| Kata berisiko dalam konteks | Kata yang ditandai skrip tidak menyesatkan pembeli | etsy-listing-copy-builder |
| Tag benar | Tiap tag benar untuk produk | etsy-tag-attribute-mapper |
| Kategori dan atribut | Diisi dari formulir, bukan asumsi | etsy-tag-attribute-mapper |

## File

| Butir | Lulus bila | Diperbaiki oleh |
|---|---|---|
| Paket lulus G4 | Manifest ada, verdict bukan fail | wall-art-download-package-builder |
| File yang diunggah adalah file akhir | Daftar `digital_files` sama dengan `deliverables` di manifest | wall-art-download-package-builder |
| Panduan cetak ikut | PDF panduan ada di paket atau di dalam ZIP | wall-art-print-instruction-writer |
| Jenis file diterima | Jenis file ada di daftar yang terverifikasi di catatan fakta; bila belum terverifikasi, warn | etsy-policy-fact-checker |

## Hak dan kebijakan

| Butir | Lulus bila | Diperbaiki oleh |
|---|---|---|
| Hak karya | Semua bahan cleared, atau restricted dengan syarat terpenuhi dan tercatat | studio-asset-rights-register |
| Hak mockup | Template atau latar ruangan tercatat di register hak | studio-asset-rights-register |
| Tanpa unsur dilindungi | Tidak ada karakter, logo, merek, atau gaya seniman yang dikenali | studio-asset-rights-register |
| Fakta segar | Catatan fakta kurang dari 90 hari | etsy-policy-fact-checker |

## Harga

| Butir | Lulus bila | Diperbaiki oleh |
|---|---|---|
| Harga diputuskan pemilik | Ada KEPUTUSAN pemilik, bukan hanya usulan | etsy-digital-pricing-modeler |
| Bersih per pesanan positif | Model harga menunjukkan sisa di atas nol | etsy-digital-pricing-modeler |

## Lembar unggah (disusun setelah siap)

1. Urutan gambar dan nama filenya.
2. Judul siap tempel.
3. Deskripsi siap tempel.
4. Tag (satu per baris).
5. Kategori dan atribut.
6. Harga dan jumlah stok untuk produk digital.
7. Daftar file digital sesuai urutan unggah.
8. Pengaturan lain yang perlu dipilih pemilik di formulir (jenis listing digital, perpanjangan otomatis, kebijakan toko).
