# Pola Balasan Pelanggan

Kerangka, bukan teks mati. Sesuaikan dengan fakta pesanan dan dokumen studio. Ganti bagian dalam kurung siku; hapus yang tidak berlaku.

## Bentuk umum

1. Tanggapi: sapa dengan nama depan bila ada, akui pertanyaan atau perasaannya dalam satu kalimat.
2. Jawab: jawaban langsung, langkah bernomor bila ada lebih dari dua langkah.
3. Langkah berikut: apa yang bisa dilakukan pembeli atau studio selanjutnya.

## Tidak menerima kiriman (mengira barang fisik)

```
Hi [name], thanks for reaching out. This listing is a digital download, so nothing is shipped by mail. Your files are ready in your Etsy account: go to "Purchases and reviews", find this order, and choose "Download files". If you tell me the frame size you have, I'm happy to point you to the right file.
```

## Cara mengunduh

```
Hi [name], happy to help. On a computer, sign in to Etsy, open "Purchases and reviews", and click "Download files" next to your order. Downloads work best from a web browser rather than the app. Let me know if anything doesn't show up.
```

`[CEK: langkah unduh di Etsy masih sama; lihat pusat bantuan Etsy]`

## File mana untuk ukuran tertentu

```
Hi [name], for a [size] frame, use the file named [file name]. It is set up for the [ratio] ratio, which also covers [other sizes]. The included print guide lists every size as well.
```

## Meminta ukuran yang tidak ada

Bila batas layanan studio menolak ukuran khusus:

```
Hi [name], thank you for asking. At the moment the files come in the sizes listed in the description, and I'm not able to offer custom sizes. The [ratio] file is the closest match for [requested size]; many print shops can add a small border to fit.
```

## File tidak bisa dibuka

```
Hi [name], sorry for the trouble. A few things usually fix this: 1) download on a computer rather than a phone, 2) if the file ends in .zip, double-click it to unzip first, 3) open the JPG with any photo viewer. If it still won't open, tell me which file and what device you're using and I'll sort it out.
```

## Warna cetak berbeda dari layar

```
Hi [name], thank you for letting me know. Printed colors can look a little different from a screen because every screen, printer, and paper handles color differently. A matte photo paper and the "best quality" setting usually get closest. I'm happy to suggest settings if you tell me how you printed it.
```

## Permintaan custom

Bila produk custom belum dibuka:

```
Hi [name], thank you for the lovely idea. I'm not taking custom orders at the moment, but I'm noting your request for future collections.
```

## Balasan ulasan baik (publik)

```
Thank you so much, [name]. I'm glad it found a good spot on your wall.
```

## Balasan ulasan kurang baik (publik)

```
Thank you for the feedback, and I'm sorry this wasn't what you expected. Please send me a message so I can help make it right.
```

Tanpa rincian pesanan, tanpa pembelaan, tanpa menyalahkan.

## Yang tidak ditulis

- Janji refund, penggantian, atau tenggat yang belum diputuskan.
- Ajakan bertransaksi di luar Etsy, atau imbalan untuk ulasan.
- Jaminan warna dan mutu cetak.
- Data pribadi pembeli di luar nama depan.
